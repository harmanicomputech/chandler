# Admin User Guide — Chandler CMS

_For City of Chandler tourism and economic development staff. No technical knowledge needed._

## Signing in
Go to **/admin** and sign in with your City e-mail and password. After 5 wrong passwords the account locks for 15 minutes. Sessions end after 8 hours. Always **Sign out** on shared computers.

## The dashboard
Shows counts for both websites, items **waiting for approval**, the latest form **submissions**, upcoming events, integration health and recent activity.

## Editing a page, listing or event
1. Choose the type in the left menu (e.g. **Listings**). Search or filter by status/site/type.
2. Click the name to open it. Edit fields; use the toolbar for headings, bold, lists and links. (*HTML* shows the source.)
3. Choose an image with **Choose…** (images come from the Media library).
4. Open **SEO & social** to set the search title and description (keep descriptions ~155 characters).
5. Press:
   * **Save draft** — saves without changing what the public sees (if it is new, it stays hidden).
   * **Publish** — makes it live immediately (editors). Staff without publishing rights see **Submit for approval** / **Request publish** instead; an editor will approve it.
   * **Archive** — removes it from the website without deleting it.
6. **Scheduling:** set *Publish at* to go live later, *Expire at* to disappear automatically (e.g. an event promotion).
7. **Mistake?** Scroll to **Version history** and press **Restore** on an earlier version (it comes back as a draft for you to check and publish).

Changing a page's **URL path** automatically redirects the old address — no broken links.

## Events submitted by the public
**Submissions → filter "event"** → open the submission → **Approve & create draft**. Review the new draft event (add a photo, check the dates), then **Publish**.

## Partner (stakeholder) updates
Partners propose changes in their portal. Open the submission, read the proposed values, then **Approve & apply changes** (the old version is saved) or set status **Rejected** with a note.

## Economic development enquiries
Investor, property, site-selection and "Let's Talk Business" enquiries arrive in **Submissions** (site: EDO). Assign to a team member, add internal notes, and set status *In progress → Closed*. If the CRM connection is enabled each enquiry is also sent to the CRM; use **Retry CRM sync** if the dashboard shows failures.

## Properties & economic data
* **Properties**: add or update available buildings/land. Tick *Zoning verified* only after Development Services confirms. Records marked *Demonstration fixture* are examples and must be deleted before launch.
* **Economic data**: every number needs a **source name, source URL and "as of"** — the public data portal shows them next to each figure.

## Media library
Upload JPEG/PNG/WebP (≤15 MB). **Alt text is required** — describe what the photo shows for people using screen readers. Set **Reuse rights** to *Approved* only when the City holds the rights; *Restricted* images must not be used.

## Navigation & redirects
**Navigation**: choose the website and menu, edit labels/links/order, untick *Visible* to hide. **Redirects**: add old → new paths when retiring pages (301 = permanent).

## Users (administrators only)
**Users & roles → New user**: name, e-mail, role, which website(s), initial password (12+ characters with letters and numbers). Disable leavers by unticking *Account active* (they are signed out immediately).
